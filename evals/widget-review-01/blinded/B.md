# LatestPosts data reliability review

Read-only review of commit `98098b9c4b5928f89f338203193c2bf40ab7f38c`. Repository `CLAUDE.md` reviewed; no AGENTS.md found. No app edits, builds, device runs, or network requests performed.

## Actionable findings

1. **P1 — Account removal has no widget invalidation or fresh credential validation.** [AppAccountsManager.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/Packages/AppAccount/Sources/AppAccount/AppAccountsManager.swift:30) creates a process-local singleton, reads Keychain only during initialization (32–45), and mutates only its local accounts when adding/deleting (47–65). [AppAccountEntity.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppIntents/AppAccountEntity.swift:25) resolves identifiers and suggestions from that cached array (25–38). The provider trusts the account object it receives, and [SharedUtils.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/Shared/SharedUtils.swift:15) creates its client directly from that object's server/token. Repository-wide search found no `WidgetCenter`, `reloadTimelines`, or `reloadAllTimelines` calls. Thus an already-running extension has no source-level way to notice the app's account deletion, and an existing displayed entry receives no explicit invalidation. **Correction:** resolve the configured ID against fresh shared account storage per load; reject removed IDs without substituting another account; recheck account membership/generation before publishing an awaited result. After committed account changes, request a LatestPosts reload and invalidate that account's widget cache. An actual post-logout display duration or successful request with old credentials depends on extension reuse, framework re-resolution, and server token validity; source does not establish those outcomes universally.

2. **P2 — Timeline request failure is indistinguishable from successful emptiness.** [SharedUtils.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/Shared/SharedUtils.swift:16) catches every request/decoding error and returns `[]` (38–39). [LatestPostsWidget.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/LatestPostsWidget/LatestPostsWidget.swift:51) then publishes those statuses in a new entry dated now (51–63). No application-level last-successful widget payload is read or retained on this path. A transient outage therefore produces a valid-looking empty result rather than an error/stale result. **Correction:** return a throwing or explicit result, separating success-with-zero-posts from failure. Persist a small last-successful payload keyed by account identity/server and timeline, with fetched-at time; reuse only the matching, still-authorized account's payload on transient failure. Do not reuse it after account removal/authentication failure. Preserve genuine successful empty responses and provide an explicit unavailable state when there is no cache. HTTP caching by URLSession may sometimes avoid a failure; it does not change the catch-path defect.

3. **P2 — One failed avatar discards all successfully fetched posts.** The private [loadImages](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/LatestPostsWidget/LatestPostsWidget.swift:77) uses a throwing task group; any transport exception escapes iteration (78–89). Its caller places both text and avatars inside one `do/catch`, and the catch constructs an empty statuses entry (55–73). This applies even when the timeline request succeeded and only one avatar host is unreachable. The view already supports missing images via a placeholder circle ([PostsWidgetView.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/Shared/PostsWidgetView.swift:70), 72–81). **Correction:** make avatar loading best-effort per URL, retain successful images, and always retain successfully fetched text. Image decode failure already yields nil without throwing; transport errors should degrade similarly. Change the provider's private loader, not only the identically named shared helper.

4. **P2 — Timeline entity lookup ignores requested identities.** [TimelineFilterEntity.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppIntents/TimelineFilterEntity.swift:26) returns all four timelines for every identifier list, including unknown or empty lists. This violates the query's stated identity operation and makes restored configuration resolution unnecessarily ambiguous. **Correction:** filter supported entities by the requested IDs, returning no match for unknown IDs; keep `suggestedEntities` as the full list. Source proves the wrong result set; it does not prove WidgetKit necessarily switches to Home or selects the wrong timeline.

## Valid behavior and limits

- Account selection is explicit ([LatestPostsWidgetConfiguration.swift](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/LatestPostsWidget/LatestPostsWidgetConfiguration.swift:8), 8–12). Switching the app's active account need not retarget an already configured widget. The status client uses the selected entity, not the current-account singleton. ID matching in the account query is correct for its available snapshot (25–30).
- Missing account/timeline returns an empty entry before networking (provider 40–50). A placeholder is synchronous sample data (9–15). Snapshot, however, performs the full network path (17–27); a cached/sample preview path would avoid outage-induced snapshot delays.
- Filtering boosts/empty text and capping counts is deliberate (SharedUtils 24–33). Six fetched posts can all be excluded; an empty result alone does not prove a network problem.
- App and widget declare matching App Group and Keychain group expressions ([widget entitlements](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesAppWidgetsExtension/IceCubesAppWidgetsExtensionExtension.entitlements:5), 5–13; [release entitlements](/var/folders/1j/zc6gngw91xzbb38rzmq7tgvr0000gn/T/ios-skill-real-app-fi9bxg6l/IceCubesApp/IceCubesApp/App/IceCubesApp-release.entitlements:19), 19–31). Missing entitlements are not demonstrated.
- `.atEnd` with one current entry is not a deterministic retry timer. A bounded `.after` retry/backoff can express recovery intent, but actual reload timing remains a device question.
