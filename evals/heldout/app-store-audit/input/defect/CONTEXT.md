# Context

ReceiptBox is a small iOS 17+ app that scans paper receipts and stores them as PDFs
on device. It uses only first-party frameworks (SwiftUI, VisionKit, Foundation); there
are no third-party SDKs. The submission files for build 57 are in this folder.

Build 57 was uploaded to App Store Connect and shortly afterwards the team received an
email from Apple about the build mentioning an issue with the privacy manifest
("ITMS-91053: Missing API declaration"). The team believes they already added a
privacy manifest and does not understand what is still missing.

Please review the submission files for readiness.
